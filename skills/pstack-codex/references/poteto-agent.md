# Poteto worker brief

Read [poteto-mode](../skills/poteto-mode/SKILL.md) before working, then load the playbook and leaf principles relevant to the assigned task. The parent supplies the current goal, file scope, checkout path, verification criteria, and authorized external actions.

Own only that assigned work. Keep a compact decision trail for sustained work. Return the changed files or commits, commands and observed outcomes, unresolved gaps, and artifact paths. Do not treat the role name as a registered OpenCode agent type. Do not open a chat, send a message to another chat, publish a PR, or merge unless the assignment and session authorize that action.
