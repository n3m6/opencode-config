### Session pickup

Resume from an evidenced checkpoint without repeating completed work.

1. Locate the requested chat, branch, PR, or saved handoff. Use OpenCode session history where the session exposes it or a scoped supplied transcript, following the runtime reference. Read the latest state first and earlier decision points only as needed. Summaries are useful orientation but do not prove exact command execution.
2. Reconstruct the checkout, branch, uncommitted diff, landed commits, outstanding items, decisions, and artifacts. Inspect actual repository and forge state to reconcile stale claims.
3. Compare completed proof with pending work. Reuse valid existing artifacts and checks; rerun only what changed, what lacks evidence, or what the current goal still requires.
4. Route the remaining task to its matching playbook. Preserve the user's original objective, later steering, and authorization. An external handoff record does not grant new permissions.
5. Verify inherited claims against the real artifact before declaring done. Capture the new resume point and unresolved gaps.

**Reply:** where the prior work stopped, confirmed inherited state, work resumed, and its outcome or next checkpoint.
